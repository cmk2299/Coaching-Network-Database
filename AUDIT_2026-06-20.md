# Product Audit 2026-06-20 — Data Engineering · CTO · CIO

Three parallel perspective-audits (read-only, evidence-grounded). Below: the
convergent findings, what was **fixed in this pass**, and what **needs your

## ✅ Fixed in this pass (safe, high-leverage, deployed)

1. **DSGVO — stop public indexing of PII.** `output/vercel.json` now sends
   `X-Robots-Tag: noindex, nofollow, noarchive` on every response; added
   `output/robots.txt` (Disallow: /). Mitigates the largest exposure: ~99k EU
   individuals' personal data (dob, nationality, agent, incl. youth) was openly
   indexable. **NOTE:** this stops indexing, not access — see "Needs decision #1".
2. **Deploy quality gate.** `run_mvp.sh` Step 4b now runs `logic_audit.py` +
   `scoring_audit.py` and **blocks deploy** on any defect (override `SKIP_GATE=1`).
   Root-cause guard against the recurring silent-regression class.
3. **Content-level smoke test.** Post-deploy check now asserts the live index has
   ≥50 coach rows, not just HTTP 200 (a blank build returns 200 too).
4. **SQLite FK integrity gate.** `build_sqlite.py` now runs `PRAGMA
   foreign_key_check` at end, reports the count (was a false "0 violations" claim
   in docs; ~79 staff→persons orphans actually exist), `--strict` fails the build.
5. **Reproducible builds.** `requirements.txt` pinned to exact versions (was all
   `>=`, risking a silent bs4/lxml/requests major bump changing scrape parsing);
   streamlit marked optional/legacy.
6. **Durable scrape work-list.** `refresh_player_clubs.py` ID-list default moved
   from `/tmp` (reboot-wiped → unrecoverable universe) to `data/work/`.

## ⚠️ Needs your decision (cannot/should not do unilaterally)

1. **[P0 legal] Auth-gate the site + legal review.** It's an internal Berater
   tool but served at a public URL with no auth. Add Vercel password protection
   / SSO (project setting — your action). Then: GDPR Art.6 basis + Art.14 notice
   + retention/erasure + a DPA, and a legal opinion on Transfermarkt ToS for
   **commercial** use (the data foundation is scraped from a single third party
   with no license; resale raises the stakes). This is the #1 business risk.
2. **[P0 continuity] Offsite backups.** `data/` (2.1GB) + `persons_master.json`
   (289MB) live only on one Mac; a full wipe already happened once
   (2026-05-21). Needs a destination + creds (S3/B2/rsync) to wire a nightly
   versioned backup. Also: `run_mvp.sh` and CSS assets are **untracked in git** —
   commit them (the wipe lost un-versioned CSS).
3. **[P0 maintainability] Decompose `build_network()`** — a single 2,123-line
   function holds the core IP, untestable, where every "PATTERN NN" fix accretes.
   Large refactor; should be planned + done behind tests.
4. **[P1] CI + real tests.** `tests/` is empty though CLAUDE.md claims "47 tests
   passed". Stand up GitHub Actions (pytest + ruff) and real unit tests for
   `lib/normalization.py`.
5. **[P1] Serve from DB, stop embedding network JSON in HTML.** 2.4GB/5.4k-file
   output forces fragile `--archive=tgz` deploys and is the main data/dashboard
   drift source. `output/coaches.db` is currently 0 bytes (intended serving path
   unused).
